Прокси браузера

Один прокси для всех обычных вкладок этого профиля, включая HTTP- и HTTPS-сайты.

Загрузка настроек прокси…

Логин и пароль доступны только для HTTP. SOCKS5 в Chromium работает без авторизации. Для HTTP с авторизацией оставьте только логин, если пароль пустой. Пароль сохраняется локально в профиле без шифрования и синхронизации.

Что важно знать о прокси

При отключении возвращается прежнее управление прокси. Недоступный прокси может остановить загрузку сайтов — тогда нажмите «Отключить». Это не VPN: localhost, WebRTC/UDP и часть служебного трафика могут идти напрямую. Для авторизации в инкогнито разрешите расширению работу в этом режиме.

Попап показывает действующие настройки прокси браузера, адрес и тип сервера. Статус не проверяет доступность сервера или авторизацию. Диагностические запросы не отправляются.
